# AI政策文本测评系统——部署交付说明

这是完整的服务器项目包。系统打开后直接进入测评工作台，不需要注册和登录。

## 已实现

* 六个评价对象横向比较：良策智能体、DeepSeek、Kimi、GLM5.3、Qwen3.7、HY3
* 支持直接粘贴文本，或上传 TXT / MD / DOCX / PDF / HTML 文件
* 八维100分评价：事实与政策一致性、可靠性与证据可核验性、问题针对性、政策可行性、政策创新性、预期效果与可评估性、分析逻辑与约束识别、咨政规范与表达效率
* 通用政策领域：产业经济、社会治理、民生与公共服务、资源环境、科技与数字治理、区域与城乡发展、公共安全与应急、综合政策
* 良策智能体不足与缺陷诊断
* “原文审校”功能：按原文句段标记问题，右侧给出编号、问题说明、修改建议和建议改写模板
* 人工复核：可由同行、政府部门或研究人员对各维度人工修正并填写意见
* Word测评报告与CSV结果导出
* 结果地址使用随机访问令牌，避免公开枚举历史记录

## 重要说明

本系统取消账户体系后，任何能够访问网站的人都可以新建测评。正式公网部署时，建议至少采用以下一种访问控制：

1. 仅部署在校园网/单位内网；或
2. 在 Nginx / 网关层配置统一身份认证；或
3. 通过防火墙限制允许访问的IP段。

结果页本身使用高强度随机令牌访问，不在首页公开列出全站历史记录。
